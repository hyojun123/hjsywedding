# images

이 폴더에 사진을 넣고 `index.html` 상단의 `CONFIG`에서 파일명을 지정하세요.

| 파일 | 용도 | 권장 |
|---|---|---|
| `cover.jpg` | 커버(첫 화면) 대표 사진 | 세로 3:4, 긴 변 1600px 내외 |
| `groom.svg` | 신랑 프로필 (일러스트) | 정사각형. 사진으로 바꾸려면 600×600 |
| `bride.svg` | 신부 프로필 (일러스트) | 정사각형. 사진으로 바꾸려면 600×600 |
| `g1.jpg` … | 갤러리 사진 | 정사각형으로 잘려 보임, 1000×1000 내외 |

- 파일을 넣기 전에는 자동으로 자리표시자 이미지가 보입니다.
- 갤러리 사진은 `CONFIG.gallery` 배열에 넣은 순서대로 표시됩니다.
- 사진 한 장당 300KB 이하로 줄이면 모바일에서 훨씬 빠릅니다. (squoosh.app 등 사용)
